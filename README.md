# Caderno-Tem-tico-Educa-o-Financeira-B-sica-Organiza-o-Financeira-Pessoal
Caderno temático sobre Educação Financeira Básica, com foco em organização financeira pessoal. O projeto reúne fontes confiáveis, utiliza o NotebookLM para apoiar os estudos e apresenta conceitos como planejamento, controle de gastos, reserva de emergência, investimentos e consumo consciente.
